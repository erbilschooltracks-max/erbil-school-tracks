# Erbil SchoolTracks

وێبسایتێکی RTL بە HTML، CSS و JavaScript بۆ بەڕێوەبردنی قوتابیان و ناونیشانیان لە هەولێر.

## تایبەتمەندییەکان
- داشبۆردی کوردی سۆرانی (RTL) و دیزاینی سپی
- زیادکردن و سڕینەوەی قوتابیان، شۆفێران و پاس/تەکسی
- نەخشەی Leaflet + OpenStreetMap
- دیاریکردنی شوێن بە کلیک لە نەخشە یان GPSی وێبگەڕ
- داتای دیمۆ لە localStorage
- پەیوەندی ئامادەکراو بۆ Supabase

## گرنگ: دیمۆ بەرامبەر بە داتابەیسی ئۆنلاین
بە بنەڕەت وێبسایتەکە داتای نموونەیی لە localStorage بەکاردەهێنێت. ئەمە داتابەیسی ئۆنلاین نییە و تەنها لە هەمان وێبگەڕدا دەبینرێت.

### چالاککردنی Supabase
1. لە https://supabase.com پڕۆژەیەک دروست بکە.
2. لە Dashboard ـەکەت URL و `anon` / `publishable` key بدۆزەرەوە.
3. لە `js/config.js` دایانبنێ:
   ```js
   window.APP_CONFIG = {
     SUPABASE_URL: "https://YOUR_PROJECT.supabase.co",
     SUPABASE_ANON_KEY: "YOUR_PUBLIC_ANON_OR_PUBLISHABLE_KEY"
   };
   ```
4. ناوەڕۆکی `supabase/schema.sql` لە SQL Editor جێبەجێ بکە.
5. پێش بەکارهێنانی ڕاستەقینە، Authentication و Row Level Security (RLS) policy ـە تایبەتەکان دروست بکە. SQL ـی ئێستا هیچ policy ـی گشتی دانانێت؛ بۆیە داواکارییەکان بەبێ policy ڕەت دەکرێنەوە.
6. لە local server کارپێی بکە. بۆ نموونە لە VS Code زیادکراوی **Live Server** بەکاربهێنە، پاشان `index.html` بکەرەوە.

## پاراستنی زانیاری
- `service_role` key مەخە ناو JavaScript، HTML یان GitHub.
- تەنها anon/publishable key لە frontend بەکاربهێنە؛ RLS دەبێت لە داتابەیسدا زانیاریی قوتابیان بپارێزێت.
- ئەم پڕۆژەیە لە ئێستادا چوونەژوورەوە و ڕۆڵی بەڕێوەبەر/شۆفێر/دایک‌وباوک جێبەجێ ناکات. پێش بەکارهێنانی ڕاستەقینە پێویستە ئەمانە زیاد بکرێن.
- دیاریکردنی GPS لە وێبگەڕدا زۆرجار پێویستی بە HTTPS یان localhost و مۆڵەتی بەکارهێنەر هەیە.
- شوێنی قوتابیان داتای هەستیارە؛ تەنها بە ڕەزامەندی و بۆ کەسانی مۆڵەتپێدراو پاشەکەوتی بکە.

## سنووری ئەم وەشانە
- شوێنی قوتابیان پاشەکەوت دەکرێت؛ شوێنی زیندووی پاس، ڕێڕەوی ئۆتۆماتیک و ETAی هاتووچۆ هێشتا زیاد نەکراون.
- بۆ ڕێڕەو و کاتی گەیشتن، خزمەتگوزاریی routing/ETA پێویستە.
- خزمەتگوزاریی نەخشە و میزبانی خۆڕایی سنووری بەکارهێنان هەیە.

## فایلەکان
- `index.html`: ڕووکار
- `css/style.css`: دیزاین
- `js/config.js`: ڕێکخستنی Supabase
- `js/app.js`: CRUD و داشبۆرد
- `js/map.js`: نەخشە
- `supabase/schema.sql`: خشتەکانی داتابەیس
